# PayFlow

A personal finance and payment dashboard built with React.

## Features
- View account balance
- Send money using a demo UPI flow
- Verify payments using a demo PIN
- View transaction history
- Refund transactions
- View spending analytics
- Save data using localStorage

## Technologies
- React
- Vite
- Tailwind CSS
- JavaScript
- LocalStorage

## Run Locally

1. Clone the repository.
2. Install dependencies:

   npm install

3. Start the development server:

   npm run dev
